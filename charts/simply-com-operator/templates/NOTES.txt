simply-com-operator {{ .Chart.AppVersion }} is installed in {{ .Release.Namespace }} with owner id "{{ .Values.ownerID }}".

Next, store a Simply.com API key (Account, API keys in the control panel) and create an account:

  kubectl -n {{ .Release.Namespace }} create secret generic simply-com-api-key --from-literal=apiKey=<key>
  kubectl apply -f - <<YAML
  apiVersion: simplycom.petersr.github.io/v1alpha1
  kind: ClusterAccount
  metadata:
    name: default
  spec:
    apiKeySecretRef:
      name: simply-com-api-key
      namespace: {{ .Release.Namespace }}
  YAML

Then declare records:

  kubectl apply -f - <<YAML
  apiVersion: simplycom.petersr.github.io/v1alpha1
  kind: DNSRecord
  metadata:
    name: www
  spec:
    accountRef:
      name: default
    zone: example.com
    name: www
    type: CNAME
    data: example.net
  YAML

  kubectl get dnsrecords -A
